# 视觉规范

## 当前展示

周剩余额度采用任务栏双行纯文字读数：上方“GPT剩余额度”，下方例如“62%”。采用用户2026-09-16给定的双行标准，数值仍为原Codex周剩余额度，不改为金额。

- 视觉透明；无胶囊、可见底板、边框、阴影或状态色条。原生分层窗口使用1/255黑色Alpha作为不可见命中层，避免文字间隙和留白点击穿透。
- 字体 Microsoft YaHei UI / Segoe UI；标题9 DIP、Regular、75%不透明度，百分比13 DIP、SemiBold、100%不透明度。不对字号再次手动乘DPI。
- 浅色任务栏文字 #1F1F1F，深色任务栏文字 #FFFFFF；以系统任务栏主题而非应用主题判定，高对比度使用系统文字色。本轮不新增额度阈值配色。
- 两行水平居中，整体垂直居中，默认行高且行间无额外间距，不换行、不省略。宽度为两行较宽的实测宽度加16 DIP并取整，左右各8 DIP；高度至少34 DIP并足以容纳两行。开启像素对齐和布局取整，继续使用任务栏安全位置计算。
- 常驻仅显示标题和百分比；更新时间、重置时间、连接及过期状态保留在悬停提示和无障碍信息中。
- 桌面浮窗同步使用纯文字样式，保留透明区域拖动、置顶、隐藏和不进入Alt+Tab。

## 交互

任务栏模式为真正的任务栏子窗口，自动选取不遮挡系统按钮的安全空位；没有空位时临时隐藏，遵循任务栏隐藏和全屏行为。托盘“嵌入任务栏”可切换回桌面模式。

任务栏整个文字区域使用手形指针，点击立即只读刷新额度；正在刷新时合并重复点击。桌面模式保留拖动。托盘刷新、显示隐藏和退出等功能不变。数据更新不使用动画，不恢复五小时额度或重置次数。旧40%胶囊背景和左侧色条已被本轮纯文字要求替代；主题资源中保留的颜色不代表仍需绘制背景。
